** The Problem of the Map and the Territory
/Alfred Korzybski (1933): the map is not the territory.
The word is not the thing. The model is not the reality.
Every framework in this document — every OAKOC analysis,
every psychological model, every strategic framework —
is a map. Maps are useful precisely because they simplify.
They are dangerous precisely for the same reason.

The Analyst reads reality. But what the Analyst reads is already
a construction — shaped by prior models, prior experience,
neurological priors, linguistic categories, cultural assumptions.
The raw signal never arrives unmediated.

The first question of the architecture is therefore not
"how do I read reality accurately" —
it is "what is the nature of the gap between my reading
and what is actually there, and how do I work with that gap
honestly rather than pretending it doesn't exist?"/

** Epistemology — What Can Be Known
/The formal philosophical discipline of knowledge:
what it is, how it is acquired, what its limits are.

Plato: knowledge as justified true belief —
but what justifies the justification?
Hume: all knowledge derives from sensory experience,
but sensory experience is not self-validating.
Kant: the mind does not passively receive reality —
it actively constructs it through categories of understanding
that are built into the structure of the perceiving mind itself.
The thing-in-itself (das Ding an sich) is permanently inaccessible.
What we encounter is always the thing as it appears to us,
filtered through the apparatus of perception.

This is the epistemological foundation of the Prime Constraint.
Epistemic legitimacy does not mean access to raw truth.
It means the most rigorously examined, most honestly held,
most transparently sourced approximation of truth available —
held with the permanent acknowledgment that it is an approximation./

** The Constructed Nature of Perception
/Neuroscience has confirmed what Kant argued philosophically:
the brain does not receive reality — it predicts it.

Predictive processing theory (Karl Friston, Andy Clark):
the brain is a prediction machine that continuously generates
models of the world and updates them when sensory input
contradicts the prediction. What we experience as perception
is not the world arriving — it is the brain's best current model,
corrected at the edges by incoming data.

The Analyst does not see what is there.
The Analyst sees what the brain predicts is there,
corrected by what contradicts the prediction.
This is why the Witness exists — to catch the moments
when the prediction is running louder than the correction./

The philosophical implications are contested but the phenomenon is not.
At the most fundamental level of physical reality,
the separation between observer and observed is not clean.
The Analyst is not standing outside reality reading it.
The Analyst is inside reality, and its reading is part of what

** What Version Control Is

Version control is the practice of recording every meaningful change
to a document or system over time — preserving not just the current state
but the full history of how it became what it is, why each change was made,
and what the previous states were so any of them can be recovered.

For code, this is standard. For a living philosophical and operational
document like this one, it is equally necessary — because the Architecture
of the Shapeshifter will be wrong in specific ways that cannot yet be seen,
and the ability to identify what changed, when, and why is the mechanism
that turns those errors into learning rather than silent drift.

Version control applied to this document means:
— Every significant revision is a named, described commit
— The reason for the change is recorded alongside the change itself
— Any previous version can be recovered exactly
— The history of the document's thinking is as permanent as the document itself
— Mistakes are not erased — they are recorded as the data that produced
   the next version

This is the Integration component of the Operating Loop
made structural and permanent. The loop that cannot show
its own revision history cannot verify that it is actually learning.

** Git — The Foundation Layer

Git is the distributed version control system underlying this workflow.
Git stores the full history of every file in a hidden `.git` directory.
Every commit is a snapshot of the entire repository at a point in time,
identified by a SHA hash of its content.

*** Core Git Concepts

**** Repository
The `.git` directory containing the full history.
Initialized with `git init` in the directory containing this document.

**** Commit
A named snapshot of the document at a specific point in time.
Contains: the content, a message describing the change,
a timestamp, and a pointer to the previous commit.

**** Staging Area (Index)
Git's intermediate layer between working files and committed history.
`git add <file>` stages a file.
`git commit -m "message"` commits everything staged.

**** Branch
A named pointer to a specific commit.
`git branch <name>` creates a branch.
`git checkout <name>` switches to it.
`git merge <name>` integrates changes back.

**** Log
`git log --oneline` shows compact history.
`git log -p` shows the full diff of every commit.

*** Core Git Workflow for This Document

#+BEGIN_SRC bash
git init
git add architecture-of-the-shapeshifter.org
git commit -m "v0.1: initial structure"

# After every significant revision
git add architecture-of-the-shapeshifter.org
git commit -m "v0.8: cognitive profile added"

# View full history
git log --oneline

# See exactly what changed in any commit
git show <commit-hash>

# Recover any previous version
git checkout <commit-hash> -- architecture-of-the-shapeshifter.org

# Compare current to any previous
git diff <commit-hash> HEAD
#+END_SRC

*** Git's Limitations Relevant Here

Git requires explicit staging before every commit.
If working without running `git add` and `git commit`,
the change is not tracked.

Git also treats conflicts as interruptions that must be resolved
before work can continue. This is where JJ enters.

** JJ (Jujutsu) — The Operational Layer

Jujutsu is a Git-compatible version control system implemented in Rust,
using Git repositories as physical storage backend for full interoperability,
but reimagining the mental model entirely.

*** Core JJ Concepts

**** Working Copy as Commit
Changes to files are recorded automatically as normal commits,
amended on every subsequent change. No staging. No `git add`.
Nothing is ever accidentally untracked.

**** Change ID vs Commit ID
Commits have both a commit_id (content hash) and a change_id
(stable identifier across rewrites). The change_id remains stable
even when the commit is amended, rebased, or rewritten.

**** No Staging Area
Every file change is automatically part of the current working commit.
The friction point of Git's explicit staging disappears entirely.

**** First-Class Conflicts
If an operation results in conflicts, information about those conflicts
is recorded in the commit. The operation succeeds.
Conflicts can be resolved later — there is no interrupted state.

**** Operation Log — Full Undo
Every command creates an operation in an append-only log,
enabling full undo/redo via `jj undo` and `jj redo`.
Every operation is reversible.

*** Core JJ Workflow for This Document

#+BEGIN_SRC bash
# Initialize JJ on top of existing git repo
jj git init --colocate

# Check status — also auto-commits working copy changes
jj status

# Describe the current working commit
jj describe -m "v0.8: cognitive profile and instrument section"

# Create a new empty commit to work in
jj new -m "v0.9: working on next revision"

# View the full log
jj log

# View what changed in any commit
jj diff -r <change-id>

# Edit any historical commit directly
jj edit <change-id>

# Undo the last operation entirely
jj undo

# Squash working copy changes into parent commit
jj squash

# Push to git remote
jj git push
#+END_SRC

*** Why JJ For This Document Specifically

This document is never finished. It is always in progress.
Every session produces changes that are meaningful
but often not at a clean commit boundary.

Git's model requires deciding when a change is ready to commit.
JJ's model records every state automatically and lets commits
be described and organized after the fact.

For a document that evolves through continuous philosophical refinement —
where the boundary between working and done is permanently blurred —
JJ's model is closer to how the thinking actually moves.

The Analyst observes continuously. The Architect structures in iterations.
The Integration component requires that every cycle be recorded.
JJ ensures no cycle goes unrecorded by making recording automatic.

** Operational Executability
/Every layer of this architecture must collapse into real action

conceptual level but cannot be deployed at the operational level —

under conditions that matter.

This is the most commonly violated constraint in personal development,
philosophy, and strategy. Beautiful systems that cannot be executed

Operational executability means:
— Every concept has a corresponding practice or application
— Every framework has a corresponding decision or action it produces
— Every heading, when drilled into, produces something I can
   actually do, not only something I can think about

The Shapeshifter enforces this. If the loop cannot execute it
under stress, in the field, with degraded resources and incomplete

The standard is not whether something works in calm conditions.

** The Still Point (Epoché)
/The perspective that watches without acting.
Pure awareness of what is happening —
including awareness of the other perspectives as they move.

It does not read, build, move, or return.
It simply attends.

Husserl's epoché: the suspension of judgment before interpretation begins.
The bracketing of assumption so that what is actually present
can be encountered without the noise of what was expected.
James's fringe: the awareness that is always at the edge
of whatever is focal — never absent, rarely centered.
Buddhist sati: not as a technique applied — as a natural orientation
of awareness that exists before technique is relevant.

The Still Point notices:
— When Contact is touching assumption rather than reality
— When Frame is building to avoid rather than to enable
— When Edge is moving in the wrong direction
— When Fold is processing incompletely
— When the Ground is being lost

It does not intervene directly.
It attends with precision and makes what it sees available
to the other perspectives.

Without the Still Point, the other four cannot correct themselves.
They can only continue — in whatever direction they were last pointed,
at whatever speed they last reached./

** Contact (Touch)
/The perspective that reads.
Pure awareness turned outward and inward simultaneously —
making contact with what is actually there.

Not what is expected. Not what is feared.
Not what was there before.
What is actually, precisely, presently there.

Merleau-Ponty: perception as a bodily, pre-cognitive act
of making contact with the world before the mind categorizes it.
The body knows before the mind names.
James's radical empiricism: experience as it actually arrives —
before concepts are applied, before frameworks are imposed,
before the Architect begins building on top of it.

Contact is the quality of the entire system.
If it misreads — if it touches assumption rather than reality —
everything built on that contact is misaligned.
The Frame structures a fiction.
The Edge moves through a world that isn't there.
The Fold metabolizes a false experience.

Contact is fed by the Still Point, which watches for the moment
when Contact begins touching its own prior models
rather than what is actually present./

** The Frame (Projection)
/The perspective that builds.
Takes what Contact found and gives it structure —
creates the conditions for Edge to operate in before they arrive.

Not reaction. Design.

Heidegger's projection (Entwurf): the way human existence
is always already throwing itself toward a future it is shaping.
Dasein does not encounter the future — it projects toward it,
constantly sketching the structure of what is coming
through the choices made now.

The Frame is responsible for this entire document.
Every heading is a Frame artifact — structure created in advance
so that understanding is available before the moment that requires it.

The Frame's failure mode is overbuilding —
constructing elaborate structure to avoid the discomfort
of moving through unstructured reality.
The Still Point watches for this.
The Edge corrects it by encountering what the structure
failed to anticipate and returning that encounter to the Fold./

** The Edge (Energeia)
/The perspective that moves.
Enters the world and acts inside it.
Not performing a role — expressing what the other perspectives
have produced.

Aristotle's energeia: being-at-work.
The act of a thing fully expressing its nature.
Not potential (dynamis) — actualization.
The seed becoming the tree. The capability becoming the act.
Nietzsche's will to power in its non-political sense:
the drive toward the full expression of what one is capable of becoming.

The Edge is not formless. It is multi-form.
It can take any surface form because the Ground does not change
when the surface does. Multi-form is deep structure
that can enter any environment, any context, any condition —
and remain recognizably itself while taking whatever shape
that environment requires.

Every operational section of this document is the Edge's domain —
the applied layer where the other perspectives become action./

** The Fold (Aufhebung)
/The perspective that returns.
Digests what the Edge encountered.
Turns raw experience into permanent understanding.

Hegel's Aufhebung: the dialectical movement where something is
simultaneously negated, preserved, and raised to a higher level.
Not recovery. Not simple learning.
Transformation through encounter — where what was met
becomes part of the structure that meets the next thing.

This is what prevents the system from being merely repetitive.
Without the Fold, each cycle returns to the same Contact
with the same understanding it left with.
Experience accumulates but does not compound.
The perspectives move but do not spiral.

The Fold is the mechanism that turns the loop into a spiral.
Each revolution returns to the same point but at a different level.
Contact reaches further because of what the last Edge showed.
The Frame builds differently because of what failed before.
The Edge moves through forms that would have been unavailable
before the last encounter with reality.

The Fold requires stillness. Not passivity — deliberate pause.
The journal entry. The after-action review. The honest conversation
with the Still Point about what actually happened versus what
Contact reported and the Frame planned for.

Without the Fold, experience is just cost.
With it, experience is compound interest.

Hegel's Aufhebung contains three meanings simultaneously:
to cancel, to preserve, to elevate.
The Fold does all three to every experience it processes./
