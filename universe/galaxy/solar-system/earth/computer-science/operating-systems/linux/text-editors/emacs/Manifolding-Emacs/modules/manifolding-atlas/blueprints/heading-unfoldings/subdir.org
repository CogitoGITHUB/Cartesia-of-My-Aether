#+title:      Subdirectory Prompt
#+priority:   1

* Subdirectory
Why: Organize notes into a folder hierarchy instead of dumping everything flat.
The active directory persists across creations so you can batch-create notes in
one folder, then switch.  Uses Dired-style ~read-directory-name~ to browse.

** Active Directory State
#+begin_src emacs-lisp
(defvar my/manifolding-atlas--active-dir nil
  "Persistent active subdirectory, set by `my/manifolding-atlas-set-active-dir'.
When non-nil, `my/manifolding-atlas-prompt-subdir' uses this as the default instead of
deriving it from the current buffer's file path.  The value is a directory
name string like \"test\" or \"projects/foo\" (no trailing slash).")
#+end_src

** Set Active Directory Command
#+begin_src emacs-lisp
(defun my/manifolding-atlas-set-active-dir (dir)
  "Set the persistent active directory for note creation.
Interactively, use Dired-style browsing.
With a prefix argument, clear it."
  (interactive
   (if current-prefix-arg
       (list nil)
     (let* ((root (my/manifolding-atlas-root-dir))
            (default (if my/manifolding-atlas--active-dir
                         (expand-file-name my/manifolding-atlas--active-dir root)
                       root))
            (choice (read-directory-name "Active directory: " root default)))
       (list (unless (string-equal choice (file-name-as-directory root))
               (directory-file-name (file-relative-name choice root)))))))
  (if dir
      (setq my/manifolding-atlas--active-dir (directory-file-name dir))
    (setq my/manifolding-atlas--active-dir nil))
  (message "Active dir: %s" (or my/manifolding-atlas--active-dir "(none)")))
#+end_src

** Choose Subdirectory (Core)
Implements the actual browsing/selection used by every caller (prompt-subdir,
dictionary, recipes, routines). Returns a relative path string ending in
"/" (or "" for ROOT itself), so callers can safely (concat prefix subdir slug).
#+begin_src emacs-lisp
(defun my/manifolding-atlas-choose-subdir (&optional root prompt)
  "Choose a subdirectory under ROOT via an explicit completing-read list.
ROOT defaults to `my/manifolding-atlas-root-dir'. PROMPT overrides the
default minibuffer prompt. Blank input or selecting ROOT's own path
always returns the empty string (root itself), regardless of how many
subdirectories exist. The admin directory is filtered out entirely --
reserved for internal bookkeeping."
  (let* ((root (file-name-as-directory (or root (my/manifolding-atlas-root-dir))))
         (root-label (abbreviate-file-name root))
         (subdirs
          (when (file-directory-p root)
            (sort
             (delq nil
                   (mapcar
                    (lambda (f)
                      (let ((name (file-name-nondirectory (directory-file-name f))))
                        (when (and (file-directory-p f)
                                   (not (string-prefix-p "." name))
                                   (not (member name (list "admin" "dictionary"))))
                          (file-name-as-directory name))))
                    (directory-files root t)))
             #'string-lessp)))
         (cands (cons root-label subdirs))
         (choice (completing-read (or prompt "Subdirectory: ")
                                   cands nil nil nil nil root-label)))
    (if (or (string-empty-p (string-trim choice))
            (string-equal choice root-label))
        ""
      choice)))
#+end_src

** Subdirectory Prompt (Dired)
#+begin_src emacs-lisp
(defun my/manifolding-atlas-prompt-subdir ()
  "Prompt for a subdirectory inside `my/manifolding-atlas-root-dir'.
Delegates to `my/manifolding-atlas-choose-subdir'."
  (my/manifolding-atlas-choose-subdir))
#+end_src
