#+title: Manifolding-Emacs — the running configuration

This directory is where the machine lives.
Org is not merely documentation for the machine; in important layers, the Org structures are inputs to the machine that generates its behavior.
The same principle that governs Manifolding Atlas applies here: representations are temporary, and the machinery for producing the next representation is what endures.

| Foundation | ~Manifolding-Emacs-Foundation.org~ — SINGLE SOURCE OF
              TRUTH for early-init.el + foundation-init.el.
              ~#+auto_tangle: t~ → saving it regenerates both;
              startup re-tangles before loading (static seed init.el).
              Early-init may be one save stale (visual only — harmless). |
| loader.org | The package manager itself, as Org.  foundation-init.el
              evaluates its emacs-lisp blocks directly (lexical, in
              document order) via ~my/load-literate-loader~.  There are
              no .el artifacts for it — this file is the only source. |
| modules/   | Every feature of the config, as Org files compiled and
              evaluated per-file by the loader at boot.            |

* loader.org

Sections follow the old require chain so dependencies always precede
their users:

: Vars → Errors → Org-Parse → Package-Builder → Remote
: → Compiler → Lockfile → Splash → Doctor → Entry (boot + commands)

Conventions:
- Blocks ≤ ~20 lines, one concern each, titled headings.
- Failures are LOUD — a broken block fails the boot visibly with
  the section name in the message.  Fix in place, restart.
- Loader changes take effect on **restart**, never on
  manifolding-emacs-reload (the loader cannot reload itself while
  running).

* modules/

Compiled and evaluated per-file by the loader.  See
modules/README.org for authoring rules; layer-specific agent rules
live in AGENTS.md files (modules/, modules/manifolding-atlas/…).

* Debugging a failed boot

1. The splash names the failing module/block.
2. Batch-check without the daemon:
   : emacs --batch --load ~/.config/emacs/init.el --eval '(message "ok")'
3. =(manifolding-emacs-errors-list)= holds every recorded failure.

The retired lisp/manifolding-emacs/*.el files still exist as a last-
ditch manual reference.  Nothing loads them anymore; delete them
once this path has proven itself.
