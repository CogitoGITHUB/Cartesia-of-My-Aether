#+title:      File Name Prompt
#+priority:   1

* File Name
Why: Let you override the auto-generated slug. Sometimes you want a specific
filename that doesn't match the title, or you're translating a title to a
different language for the filename.

** Default (slug from title)
#+begin_src emacs-lisp
(defun my/manifolding-atlas-prompt-file-name (title &optional subdir)
  "Prompt for a file name, defaulting to a slug of TITLE under SUBDIR.
Returns the relative file path (e.g. \"subdir/my-note\")."
  (let* ((raw-name (read-string
                    (format "File name for \"%s\" (blank = slug): " title)))
         (base (if (string-empty-p (string-trim raw-name))
                   (manifolding-atlas-title-to-slug title)
                 (file-name-sans-extension (string-trim raw-name)))))
    (concat (or subdir "") base)))
#+end_src
