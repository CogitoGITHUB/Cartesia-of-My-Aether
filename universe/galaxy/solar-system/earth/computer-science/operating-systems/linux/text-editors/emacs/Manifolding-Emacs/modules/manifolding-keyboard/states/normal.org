#+title: Manifolding Keyboard — Normal State
#+priority: 20

Keys specific to the normal state. Shared bindings live in universal.org.

** State definition
Self-registration: mode and keymap in one unit (manual activation only). Delete this file and the state unregisters on next boot.
#+begin_src emacs-lisp
(manifolding-keyboard-define-state "normal"
  :lighter "[NOR]"
  :cursor-type 'box)
#+end_src
** Bindings
#+begin_src emacs-lisp
(manifolding-keyboard-define-keys
  :states '("normal")
  :bind
  `(
    ("G" . magit-status)
    ("W" . save-buffer)
    ("e" . consult-line)
    ("h" . consult-imenu)
    ("n" . other-window)
    ("o" . consult-buffer)
))
#+end_src
