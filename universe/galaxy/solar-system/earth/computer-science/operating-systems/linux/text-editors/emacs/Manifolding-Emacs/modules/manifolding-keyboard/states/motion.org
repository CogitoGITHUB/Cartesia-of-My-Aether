#+title: Manifolding Keyboard — Motion State
#+priority: 20

Keys specific to the motion state. Shared bindings live in universal.org.

** State definition
Self-registration: mode, keymap, and init predicate in one unit. Delete this file and the state unregisters on next boot.
#+begin_src emacs-lisp
(defun my/motion-state-init-p ()
  "Auto-activate motion state in read-only buffers."
  (buffer-local-value 'buffer-read-only (current-buffer)))
#+end_src
#+begin_src emacs-lisp
(manifolding-keyboard-define-state "motion"
  :lighter "[MOT]"
  :cursor-type 'hbar :init #'my/motion-state-init-p)
#+end_src
** Bindings
#+begin_src emacs-lisp
(manifolding-keyboard-define-keys
  :states '("motion")
  :bind
  `(
    ("e" . scroll-up-command)
    ("h" . backward-button)
    ("o" . consult-outline)
    ("p" . previous-line)
    ("t" . forward-button)
    ("u" . scroll-down-command)
))
#+end_src
