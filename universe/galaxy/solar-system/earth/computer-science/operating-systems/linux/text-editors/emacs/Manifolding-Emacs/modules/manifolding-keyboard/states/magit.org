#+title: Manifolding Keyboard — Magit State
#+priority: 20

Keys specific to the magit state. Shared bindings live in universal.org.

** State definition
Self-registration: mode and keymap in one unit (manual activation only). Delete this file and the state unregisters on next boot.
#+begin_src emacs-lisp
(manifolding-keyboard-define-state "magit"
  :lighter "[GIT]"
  :cursor-type 'box)
#+end_src
