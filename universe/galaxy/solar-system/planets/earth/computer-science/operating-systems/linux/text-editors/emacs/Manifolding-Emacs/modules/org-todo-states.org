* Org TODO States
:PROPERTIES:
:ID:       9a1b2c3d-4e5f-6a7b-8c9d-0e1f2a3b4c5d
:CATEGORY: org
:END:

Define extended TODO states for all notes. Supports both the original
TODO/DONE workflow and the expanded states used by the Properties Update
Plugin and manifolding-atlas prompts.

** Config
Canonical TODO vocabulary; `org-mode.org` mirrors this value. Hook
refreshes DONE-headline font-lock on every Org buffer regardless of
load order.
#+begin_src emacs-lisp
(with-eval-after-load 'org
  (setq org-todo-keywords
        '((sequence "TODO" "NEXT" "DOING" "TESTING" "WAIT" "WARNING"
                    "|"
                    "DONE" "CANCELLED" "CANCELED"))))
(add-hook 'org-mode-hook #'org-set-regexps-and-options)
#+end_src
