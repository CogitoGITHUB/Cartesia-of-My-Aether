#+title: Manifolding Keyboard — Dired State
#+priority: 20

Keys specific to the dired state. Shared bindings live in universal.org.

** State definition
Self-registration: mode, keymap, and init predicate in one unit. Delete this file and the state unregisters on next boot.
#+begin_src emacs-lisp
(defun my/dired-state-init-p ()
  "Auto-activate dired state in dired buffers."
  (derived-mode-p 'dired-mode))
#+end_src
#+begin_src emacs-lisp
(manifolding-keyboard-define-state "dired"
  :lighter "[DIR]"
  :cursor-type 'box :init #'my/dired-state-init-p)
#+end_src
** Bindings
#+begin_src emacs-lisp
(manifolding-keyboard-define-keys
  :states '("dired")
  :bind
  `(
    ("." . dired-omit-mode)
    ("<return>" . dired-find-file)
    ("RET" . dired-find-file)
    ("a" . my/dired-ks-open-file)
    ("t" . dired-find-file)
))
