Native Emacs client for OpenCode: start servers, open sessions, chat,
stream responses — all from Emacs buffers.

** Config
#+begin_src emacs-lisp
  (with-eval-after-load 'emacs-opencode
    (setq opencode-session-default-agent "build")

    ;; Point the server at the emacs-specific opencode config
    ;; so the agent knows about emacs-mcp-server and emacsclient.
    (setq opencode-server-environment
          `(("OPENCODE_CONFIG" .
             ,(expand-file-name "~/.config/opencode/opencode.jsonc")))))
#+end_src
